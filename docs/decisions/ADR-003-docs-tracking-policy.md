# ADR: `docs/` 추적 정책을 로컬 전용 디렉터리 방식으로 전환

> date: `2026-08-25` | status: 채택
> related progress: `docs/progress/2026-08-25_docs-추적정책-전환.md`

## 맥락

CJ-001 하네스 초기화에서 "구현계획과 실제 운영 기록은 기본적으로 Git에서 제외한다"를 결정하고 `.gitignore`에 `docs/**`를 넣었다. 근거 기록은 `docs/progress/2026-08-24_하네스-초기화.md`의 결정 절이다.

실제 운영은 그 결정과 반대로 갔다. 백로그, 진행기록, ADR을 매번 `git add -f`로 강제 추가해 왔고, 이 ADR을 쓰는 시점에 `docs/` 아래 9개 파일이 추적 중이다. 규칙은 제외인데 운영은 전부 포함이다.

부작용도 실제로 발생했다. 무시된 새 파일은 `git status`에 뜨지 않는다. 그래서 위 결정을 담은 `docs/progress/2026-08-24_하네스-초기화.md` 자체가 2026-08-24 이후 커밋되지 못한 채 로컬에만 남아 있었고, 원격 `docs/progress/`에 기록 하나가 비어 있다는 사실이 드러나지 않았다. `AGENTS.md`가 작업마다 진행기록을 요구하므로 이 실패는 반복된다.

ADR-002에서 `!docs/decisions/**` 예외를 열어 ADR만 안전해졌고 진행기록·백로그는 여전히 강제 추가가 필요한 반쪽 상태였다.

## 결정과 근거

| 결정 항목 | 결정안 | 근거 | 버린 대안 |
|---|---|---|---|
| `docs/` 기본 정책 | 추적한다. `docs/**` 무시를 없앤다 | 진행기록·백로그·ADR은 인수인계 정본이라 원격에 있어야 한다 | 예외를 계속 늘린다. `!docs/progress/**`, `!docs/backlog/**` 추가 |
| 로컬 전용 자리 | `docs/local/`만 무시한다 | `.ai/local/`과 대칭이라 "local이 붙은 곳만 로컬 전용"으로 규칙 전체가 설명된다 | 로컬 자료를 저장소 밖 디렉터리에 둔다 |
| 구현계획 원문 | 저장소 밖 유지. 이번 결정으로 바뀌지 않는다. **이 행은 ADR-004가 대체한다** | CJ-001의 "구현계획 원문을 로컬 전용으로 보호한다"는 의도는 그대로 유효하다 | 저장소 안으로 옮긴다 |
| 누락된 기록 | `docs/progress/2026-08-24_하네스-초기화.md`를 추적에 넣는다 | 당시 사실의 기록이라 시간순 보존 대상이다 | 폐기한다 |

예외를 늘리는 대안을 버린 이유는 `docs/**` 무시가 사실상 아무것도 막지 못하게 되기 때문이다. 막지 못하는 규칙과 그 규칙을 무력화하는 예외 목록만 남는다.

이 결정은 CJ-001 결정 중 "실제 운영 기록도 Git에서 제외한다" 부분을 대체한다. "구현계획 원문은 로컬 전용" 부분은 유지한다.

## 가정과 위험

- 이 저장소는 공개다. `docs/` 아래 새 파일이 기본적으로 커밋 후보가 되므로, 공개하면 안 되는 자료는 `docs/local/`에 두어야 한다. 판단은 여전히 사람이 하지만, 강제 추가 방식과 달리 `git status`에 보이는 상태에서 판단한다.
- `docs/local/`은 비어 있으면 Git에 존재하지 않는다. 필요할 때 직접 만들어야 한다.

## 검증

- `git status --short`에 `?? docs/progress/2026-08-24_하네스-초기화.md`가 뜬다. 전환 전에는 `git status --ignored`로만 보였다.
- `git check-ignore -v --no-index`로 `docs/local/x.md`는 무시, `docs/progress/새파일.md`는 무시되지 않음을 확인했다.
- `pwsh -NoProfile -File tests/ai-cli.tests.ps1` 출력 `PASS: 49 assertions`.
- `pwsh -NoProfile -File .codex/scripts/test-anchors.ps1 -Strict` 출력 `anchors_checked=0 drift=0`.

## 만료 조건

- `docs/` 아래에 공개하면 안 되는 자료가 늘어 기본 추적이 위험해질 때.
- 저장소가 비공개로 바뀌어 `docs/local/` 구분이 필요 없어질 때.
