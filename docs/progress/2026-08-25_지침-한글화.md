## 목표

`feat(research-handoff)` 범위에서 영어로 커밋된 인수인계 지침을 한글로 옮겨 저장소 문서 언어를 통일한다.

## 배경 및 사유

외부 지식 정책, `.ai/` 작업공간 문서, 템플릿, ADR-001이 영어였고 하네스 문서와 진행기록은 한글이라 한 저장소 안에서 지침 언어가 갈렸다. 커밋 규약은 이미 "설명은 한글로 쓰고 코드 식별자·파일 경로·CLI 명령은 영어 원문을 유지한다"를 정해 두었으므로, 문서에도 같은 기준을 적용했다.

## 진행 내용

- `AGENTS.md`와 `CLAUDE.md`의 외부 지식 정책을 한글로 옮겼다. 두 파일 본문은 여전히 동일하다.
- `.ai/README.md`, `.ai/context/project.md`, `.ai/templates/` 4개 템플릿, `docs/decisions/ADR-001-ai-workspace-status.md`, `docs/progress/2026-08-24_ai-dev-router-v0.1.md`, `harness/ssot-index.md`의 AI 인수인계 프로토콜 행을 한글로 옮겼다.
- `.gitignore`와 `.gitattributes`의 영어 주석을 한글로 옮겼다.
- research-request 템플릿의 `## Topic`을 `## 주제`로 바꾸면서 `tools/ai/ai.ps1`의 파싱 정규식과 placeholder, `tests/ai-cli.tests.ps1`의 단언 3곳을 함께 맞췄다.
- 병합이 끝난 `.worktrees/ai-dev-router-v0.1` 워크트리를 정리했다. 워크트리에만 있던 추적되지 않는 SDD 산출물 17개는 저장소 밖 `../docs/sdd/ai-dev-router-v0.1-execution-plan/`으로 옮겨 보존한 뒤 제거했다.
- 병합이 끝난 로컬 브랜치 `feat/research-handoff-v0.1`, `feat/ai-dev-router-v0.1`을 삭제했다.

## 결정

- 문서 본문은 한글로 쓰되 코드 식별자, 파일 경로, CLI 명령, `RES-YYYYMMDD-NNN`, `WAITING`, `DONE`, CLI 표준 출력과 에러 메시지는 영어 원문을 유지한다. CLI 출력은 통합 테스트가 문자열을 그대로 검증하는 계약이다.
- research-request 템플릿의 섹션 제목은 CLI 파싱 계약이다. 제목을 한글로 옮기려면 템플릿, `tools/ai/ai.ps1`, 통합 테스트를 한 커밋에서 함께 바꿔야 한다.
