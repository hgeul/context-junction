## 프로젝트 초기화

1. `harness/project-context.md`와 `harness/ssot-index.md`가 현재 정본과 진실 기준을 가리키는지 확인한다.
2. 작업 전 `docs/backlog/작업목록.md`와 최신 `docs/progress/`를 읽는다.
3. 새 정본·외부 Source·Schema·실험 산출물은 SSOT 등록부에 먼저 추가한다.
