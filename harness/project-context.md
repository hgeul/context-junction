# Context Junction 공통 컨텍스트

## 권위 순서

1. 저장소 밖의 `../docs/context-junction_구현계획.md` (로컬 구현계획 원문)
2. `harness/ssot-index.md`에 등록된 구현·외부 계약 진실 기준
3. `docs/backlog/`, `docs/progress/`, `docs/decisions/`의 로컬 운영 기록

구현계획 원문은 현재 요구와 역할 분리의 기준이다. 진행기록은 당시 수행 사실이며 정본을 대체하지 않는다. API key, password, token, 개인정보, 원본 민감 payload를 문서·로그·커밋에 기록하지 않는다.
