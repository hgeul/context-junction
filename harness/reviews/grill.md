# grill 계약

설계 판단만 소크라테스식으로 검토한다. 결정론적 규칙 위반은 `dod`의 책임이다. 자동 수정·점수화·`PASS`/`FAIL` 판정은 하지 않는다.

`AGENTS.md`, `harness/project-context.md`, `harness/ssot-index.md`, 프로젝트 규칙과 기준선 diff를 읽고 실제 변경 영역만 다룬다. 적용되는 축마다 파일:줄 또는 문서 절과 이유를 인용해 1~3개 질문을 낸다: Source·권한·공개 시각, 데이터 계보·접근 경계, 정본·계약·호환성, 오류·실행 영향, 재현성, 작업기록·ADR·용어. 사용자가 답한 중요 결정은 `docs/decisions/` ADR에 남긴다.
